# RevvUp - A car Dealership Platform

RevvUp is a full-stack web application for browsing car catalogs, scheduling test drives and managing inventory and bookings via an admin panel.

## Live Deployments
- **Frontend (Vercel):** [revvup-frontend.vercel.app]
- **Backend (Railway):** [revvup-backend-production.up.railway.app]

---

## Tech Stack
- **Frontend:** React,React Router
- **Backend:** Node.js,CORS, Express

---

## Features
- **Car Catalog:** Search and filter vehicles by make and model.
- **Test Drive Booking:** Users can book test drives and track the approval status live.
- **Admin Panel:** Admins can update vehicle stock status and can either approve,cancel and make a test drive as complete.
